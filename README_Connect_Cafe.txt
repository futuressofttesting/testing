How to run:
1. Extract the ZIP.
2. Double-click Open_Connect_Cafe.bat.
3. The software opens in Chrome/Edge. No hosting or domain is needed.

Data:
- Data is stored locally in the browser using localStorage.
- Use Settings & Backup -> Export Backup regularly.
- To move to another PC, export a backup JSON and import it on the other PC.

V1.1 includes:
- Dashboard
- POS / Sales
- Recipes / recipe costing
- Ingredients and unit costing
- Inventory
- Purchases
- Expenses
- Waste
- Menu & Pricing
- Reports
- Settings / Backup
- Table-based POS with 12 default tables
- Open/hold orders by table until payment
- Table status: Available / Order open
- Takeaway order mode
- Manage, rename, activate/deactivate, and add tables from POS
- Pay & Close Table with Cash / Card / QR / Other
- Order notes and clear-order controls
- Enhanced dashboard with 7-day sales trend, payment mix, table occupancy, low-stock watch, top sellers, and recipe-cost watch

Note:
Instagram content itself is not embedded into the offline application because the Instagram profile could not be fetched reliably at build time. The app includes direct links to the profile so it can be opened online.


Table workflow:
- Select Table 1, Table 2, etc.
- Add drinks to the table order.
- Leave the order open and move to another table.
- Return to the table later; the order remains there.
- When the guest is ready, choose the payment method and click Pay & Close Table.
- The sale is recorded and ingredients are deducted from inventory automatically.
