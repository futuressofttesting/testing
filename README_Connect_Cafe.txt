CONNECT CAFE — MANAGEMENT V1.2 OFFLINE PACKAGE

Purpose
Connect Cafe V1.2 is a local-first cafe management prototype designed around table-based service, recipe costing, inventory, purchasing, expenses, sales, receipts and operational reporting.

How to run
1. Extract the ZIP to a folder on Windows.
2. Double-click Open_Connect_Cafe.bat.
3. The application opens in Chrome or Microsoft Edge.
4. No domain or hosting is required for normal use.

Main workflow
1. Open Shift & Cash at the start of service and enter opening cash.
2. Open POS / Sales.
3. Choose Table 1, Table 2, Takeaway, or another configured table.
4. Add drinks to the table. The order stays open while you serve other tables.
5. When the guest is ready, choose payment and review the payment screen.
6. For normal payments use one payment line. For mixed cash/card/QR payments use Split Tender and add payment lines.
7. For cash, enter the amount received. The software calculates change.
8. Choose Pay & Print Receipt to print an itemized 80mm-style receipt, or Pay & Close to finish without printing.
9. Inventory is reduced from recipe ingredients when a sale is completed.
10. Use Reports to print a detailed sales report, reprint a receipt, export CSV, or review voids.
11. Close the shift at the end of service and compare expected drawer cash with actual cash counted.

Receipt printing
- Customer receipt is formatted for an 80mm thermal-style printer.
- A normal Windows/desktop printer can also print the receipt if the printer driver supports the selected paper/page size.
- Receipt wording and identity fields are editable under Settings.

Reports
- Select From / To dates.
- Print Detailed Sales Report for a clean management copy.
- Use Receipt on a completed sale to open and reprint that customer receipt.
- Use Export CSV to export transaction details.

Data and backup
- The application stores its operational data locally in the browser (localStorage).
- Export a JSON backup frequently using Settings & Backup.
- On another computer, open the software and import the backup JSON.
- Clearing browser data can remove local application data, so backups are strongly recommended.

Important setup note
The supplied recipe quantities and ingredient purchase values were seeded as editable working/demo values from the provided handwritten recipes. Replace the ingredient purchase quantities, purchase costs and any placeholder recipe quantities with the cafe's actual values before using the system for financial reporting.

Future online version
The data model is kept modular so it can later be migrated to a server database for multi-device, multi-user and multi-branch use without changing the core workflow.
